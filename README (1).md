# ①課題名
きょうの様子メモ

## ②課題内容（どんな作品か）
- 学校に行きづらい子どもの「毎日の様子」を、親が記録するメモアプリ
- 日付、登校の様子（行けた・遅刻・別室・早退・休み）、その日のメモを保存できる（localStorage）
- 同じ日付で保存すると、その日の記録を上書きする（1日1件）。記録は日付の新しい順に並ぶ
- 1件ずつの削除と、全部消すことができる
- **曜日別グラフ**：月〜金のどの曜日に休みや遅刻が多いかが分かる
- **週ごとの推移グラフ**：直近8週で、状態が良くなっているか悪くなっているかが分かる

## ⑤工夫した点・こだわった点
- **グラフを目的から考えた**：最初は「行けた◯日・休み◯日」の合計グラフを作ろうとしたが、それでは次の行動につながらない。学校との話し合いに使えるように、「曜日別」と「週ごとの推移」の2つにした
- **グラフはライブラリを使わずに作った**：記録を数えて割合を出し、CSSの `width: ○%` で棒の長さにしている
- **棒を描く処理を1つの関数（makeStackedBars）にまとめた**：曜日別も週別も、同じ関数を使い回している
- **選択肢を配列で管理した**：「行けた・遅刻…」のボタンはHTMLに直接書かず、配列からfor文で作っている。選択肢を増やすときは配列を1か所直すだけで済む
## コードの構成

| ファイル | 役割 |
|---|---|
| index.html | 画面の部品。ボタン・グラフ・一覧の中身は空にしておき、JSで入れる |
| css/style.css | 見た目。グラフもCSSの棒の幅（%）で描いている |
| js/main.js | 動き。保存・読み出し・削除・グラフ |

**main.js の主な関数**
- `render()`：記録の一覧と2つのグラフを描き直す（保存・削除・ページを開いたときに呼ぶ）
- `makeAttendChoices()`：「行けた・遅刻…」のボタンを配列から作る
- `renderLegend()`：グラフの色の見本を作る
- 保存：`JSON.stringify` → `localStorage.setItem`
- 読み出し：`localStorage.getItem` → `JSON.parse`
- 削除：`splice`（1件）／`localStorage.removeItem`（全部）

## グラフのしくみ

ライブラリは使わず、記録を数えて、CSSの棒の長さ（%）に変えて描いている。

**入力**：保存した記録（records）
| 日付 | 様子 |
|---|---|
| 11/26（木） | 行けた |
| 11/25（水） | 行けた |
| 11/24（火） | 行けた |
| 11/23（月） | 遅刻 |
| 11/22（日） | 行けた |

**処理**
1. 箱を用意する：曜日別は月〜金の5つ。週ごとは「その週の月曜日」ごと
2. 数える：記録を1件ずつ見て、当てはまる箱の「様子」に＋1する（曜日別では土日は数えない）
3. 一番多い合計を探して、それを100%にする
4. 「その数 ÷ 一番多い合計 × 100」で、棒の長さ（%）を出す
5. 長さと色を `style="width: ◯%; background: 色"` にして、棒のHTMLを作る

**出力**
- 曜日別：月＝遅刻100%、火・水・木＝行けた100%、金＝0日
- 週ごと：11/16〜＝行けた25%（1日）、11/23〜＝行けた75%＋遅刻25%（4日）

※ 11/22は日曜なので、曜日別には出ないが、週ごとには入る

**使っている関数**
- `renderWeekdayChart()`：曜日ごとに数える
- `renderWeeklyChart()`：週ごとに数える（直近8週）
- `makeStackedBars()`：数を棒のHTMLにする（2つのグラフで使い回し）

## ⑥難しかった点・次回トライしたいこと（又は機能）
- `{` と `}` の対応がずれて、処理が関数の中に入ってしまい、動かなくなった。Consoleのエラー（行番号と関数名）を読んで直した
- 似たような `html.push(...)` の行が2か所あり、違う場所に貼ってエラーになった
- 日付から「その週の月曜日」を出す計算が難しかった
- 次回トライしたい機能：学校に伝えるためのまとめ文の自動作成、子ども自身が気持ちを記録できる「子どもモード」
