# ①課題番号-プロダクト名

kadai02 - きょうの様子メモ

## ②課題内容（どんな作品か）

学校に行きづらい子どもの「毎日の様子」を、親が記録するメモアプリです。

- 日付、登校の様子（行けた・遅刻・別室・早退・休み）、その日のメモを保存できる
- 同じ日付で保存すると、その日の記録を上書きする（1日1件）
- 記録は日付の新しい順に並ぶ
- 1件ずつの削除と、全部消すことができる
- **曜日別グラフ**：月〜金のどの曜日に休みや遅刻が多いかが分かる
- **週ごとの推移グラフ**：直近8週で、状態が良くなっているか悪くなっているかが分かる

背景：子どもが学校で困っているとき、親は「学校と何を話せばいいか」が分からないことが多いです。感覚ではなく記録をもとに、「月曜に休みが多い」などのパターンを学校に伝えられるようにすることを目指しました。

## ⑤工夫した点・こだわった点

- **グラフの目的から考えた**：最初は「行けた◯日・休み◯日」の合計グラフを作ろうとしたが、それでは次の行動につながらない。学校との話し合いに使えるように、「曜日別」と「週ごとの推移」の2つにした
- **グラフはライブラリを使わずに作った**：記録を数えて割合を出し、CSSの `width: ○%` で棒の長さにしている
- **棒を描く処理を1つの関数（makeStackedBars）にまとめた**：曜日別も週別も、同じ関数を使い回している
- **選択肢を配列で管理した**：「行けた・遅刻…」のボタンはHTMLに直接書かず、配列からfor文で作っている。選択肢を増やすときは配列を1か所直すだけで済む
- **1日1件にした**：同じ日付の記録があれば上書きする

## ⑥難しかった点・次回トライしたいこと

- `{` と `}` の対応がずれて、処理が関数の中に入ってしまい、動かなくなった。Consoleのエラー（行番号と関数名）を読んで直した
- 似たような `html.push(...)` の行が2か所あり、違う場所に貼ってエラーになった
- 日付から「その週の月曜日」を出す計算が難しかった
- 次回トライしたいこと：学校に伝えるためのまとめ文の自動作成、子ども自身が気持ちを記録できる「子どもモード」
